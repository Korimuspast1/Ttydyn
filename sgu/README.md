# Пульт СГУ — спецсигналы полиции (реальные записи + генератор)

Веб-пульт сигнально-громкоговорящей установки: нажимаешь кнопку — звучит сигнал.
Работает целиком в браузере, без сервера и без сборки: обычные HTML/CSS/JS (ES-модули).

## Что внутри

1. **РЕАЛЬНЫЕ ЗАПИСИ СИРЕН** — 15 настоящих сэмплов, снятых с работающих блоков
   (Federal Signal Vama AS-420 / AS-380, Standby RSG MCS + Rumbler, Becker Sinfo,
   Sarco SOS-106, Ulvo Sirra SOS-102). Играют по кругу, шов сшит кроссфейдом,
   есть ползунок «ТОН» (высота/темп). Источники и лицензии — `audio/real/CREDITS.md`.
2. **ГЕНЕРАТОР СИГНАЛОВ СГУ** — синтез в реальном времени: `WAIL` (сирена),
   `YELP` (крякалка), `HI-LO`, `PULSAR`, старая электромеханическая сирена,
   `ПОГОНЯ` (WAIL + YELP одновременно), `AIR HORN` (пробел, держать),
   `МИКРОФОН` (M, держать), плюс сигналы ГО «Внимание всем!» и «Воздушная тревога!».
3. **РУПОР / РЕЧЕВЫЕ ОБЪЯВЛЕНИЯ** — фразы («Освободите проезжую часть» и т. п.)
   проходят через обработку «рупор» (полосовой фильтр + перегруз + реверберация),
   при включении микрофона сирена автоматически приглушается (duck).
4. **ПОИСК НАСТОЯЩИХ ЗАПИСЕЙ В ИНТЕРНЕТЕ** — поиск по Wikimedia Commons прямо из браузера:
   результат можно послушать через рупор или сохранить в «Свои записи».
5. **СВОИ ЗАПИСИ** — drag & drop любых mp3/wav/ogg; файлы лежат в IndexedDB браузера.
6. **Маячки** — имитация балки: частота вспышек меняется от выбранного режима (крякалка быстрее, WAIL медленнее).

## Как запустить

```bash
cd sgu
python3 -m http.server 8080
# открыть http://localhost:8080
```

Подойдёт любой статический сервер (`npx serve`, `php -S`, nginx, GitHub Pages).
Открывать `index.html` как `file://` нельзя — браузер заблокирует ES-модули.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `1` … `6` | режимы сирены (вкл/выкл) |
| `Пробел` | пневмогудок (держать) |
| `M` | микрофон / объявление через рупор (держать) |
| `L` | маячки вручную |
| `Esc` | стоп — выключить всё |

## Структура

```
sgu/
├── index.html
├── css/style.css
├── js/
│   ├── modes.js    — описание сигналов (контуры частоты), список реальных записей, фразы
│   ├── engine.js   — Web Audio: генератор, рупор, duck, зацикливание записей
│   └── app.js      — интерфейс пульта, поиск записей, свои файлы (IndexedDB)
└── audio/
    ├── real/       — реальные записи сирен + CREDITS.md
    └── ph-*.mp3    — озвученные объявления (если есть)
```

## Про стандарты

Российские СГУ («Элина», «Мираж», «Смерч», «СГУ-100») и европейские блоки из раздела реальных
записей сертифицируются по одним и тем же правилам: **ГОСТ Р 50574 ↔ Правила ЕЭК ООН №65 (ECE R65)**.
Поэтому набор режимов и характер звука у них общий, а различия — в тоне и темпе развёртки;
для этого в пульте есть ползунки.

## Юридическая ремарка

Спецсигналы разрешены только оперативным службам. Установка и использование СГУ на обычном
автомобиле в России запрещены (ГОСТ Р 50574, КоАП РФ 12.4 / 12.5). Проект — для звуковых
экспериментов, монтажа, игр и реконструкций.
