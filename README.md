# WorldBox Песочница — 2D Пиксельный Симулятор Бога (PC + Android Port)

Полноценный оптимизированный 2D пиксельный симулятор Бога в духе **WorldBox** с физикой воды, сыпучих пород, эрозией, химией стихий, дипломатией королевств, войнами, зомби-апокалипсисом, чертами каждого существа, мобильным сенсорным управлением и готовым **Android `.apk`**.

## 📱 Скачать готовый Android `.apk`
- **Прямое скачивание из Releases:** [**WorldBox-Sandbox.apk (v3.5.0)**](https://github.com/Korimuspast1/Ttydyn/releases/download/v3.5.0/WorldBox-Sandbox.apk)
- **Файл в корне ветки:** [`WorldBox-Sandbox.apk`](./WorldBox-Sandbox.apk) (`~200 КБ`, `Android 7.0 – Android 15+`, подписан `v2 + v3`, работает полностью офлайн).

---

## ✨ Основные возможности
- **36 божественных сил**: песок, вода, камень, почва, лава, кислота, нефть, порох, TNT, ядерный удар, метеориты, дракон, люди, овцы, волки, зомби, скелеты, чума, благодать, дождь/потоп, снег, солнце, дипломатия и войны.
- **Оптимизированное ядро v3.5**:
  - Предзапечённые пиксельные спрайты всех юнитов и существ (`ModelAtlas`).
  - Пространственная хеш-сетка `40×25` без аллокаций GC для поиска целей, башен и стрел.
  - Спящие ячейки и активное окно реакций физики воды, сыпучих материалов и химии.
- **Удобный порт на телефон**:
  - Плавный мультитач **2 пальцами** (приближение/отдаление + перемещение камеры).
  - Боковая панель под большой палец: переключение **`🖌 КИСТЬ` / `🖐 КАМЕРА`**, зум **`＋` / `－`**, осмотр существа **`🔍`** и переход по деревням **`🏘`**.
  - Поддержка портретного и горизонтального режимов экрана, вырезов (`safe-area`), автопаузы при сворачивании, вибрации и экспорта сохранений мира `.json` в папку **«Загрузки»** телефона.

## 🚀 Запуск и сборка из исходников

```bash
# Установка зависимостей и запуск dev-сервера
npm install
npm run dev

# Production-сборка веб-версии
npm run build

# Пересборка подписанного Android APK
./scripts/build-apk.sh
```
