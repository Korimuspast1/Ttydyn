## ⌨️ Управление и фишки ПК-порта (v3.6)
- **Интерактивная мини-карта мира** (правая верхняя панель): кликните или зажмите ЛКМ для мгновенного перемещения камеры в любую точку архипелага.
- **`ЛКМ`**: применить выбранную божественную силу.
- **`ПКМ` / `СКМ` или `WASD` / `Стрелки` (+ `Shift` для ускорения `2.35×`)**: перемещение камеры (также есть опция RTS-прокрутки у краёв экрана во вкладке *«Физика и ПК»*).
- **`Колесо мыши`**: плавный зум к курсору.
- **`Ctrl + Колесо мыши`** (или `[` / `]`): мгновенное изменение размера кисти прямо на лету.
- **`Пробел` / `` ` ``**: пауза / переключение скорости симуляции (`||`, `1x`, `2x`, `5x`, **`10x`**).
- **`F5` / `F9`**: быстрое сохранение и быстрая загрузка мира на жёсткий диск ПК (`%APPDATA%\WorldBoxSandbox\saves`).
- **`F11`**: полноэкранный режим без рамок.
- **`F12`**: сохранение чёткого пиксельного скриншота в системную папку `Изображения\WorldBoxSandbox` (`Pictures\WorldBoxSandbox`).
