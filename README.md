# Duckgomz для Android

Нативное Android-приложение на Java. После регистрации открывается список с одним диалогом — официальным ботом **Duckgomz** с синей галочкой.

## Что есть

- регистрация и вход по имени пользователя и паролю — без номера телефона;
- имя пользователя проверяется по правилам Telegram (4–32 символа, латинские буквы/цифры/`_`, не начинается с цифры или `_`, не заканчивается на `_`);
- один чат Duckgomz: приветствие, текстовые сообщения, выбор и отправка файла, просмотр профиля бота;
- сообщения сохраняются локально на устройстве пользователя;
- интерфейс и часть ресурсов адаптированы из Telegram for Android. См. `THIRD_PARTY_NOTICES.md` и `LICENSE`.

## Firebase Auth

В репозиторий добавлен переданный `google-services.json` для пакета `app.duckgomz.app`. В Firebase Console нужно включить **Authentication → Sign-in method → Email/Password**.

Firebase Auth принимает email и пароль, поэтому имя пользователя преобразуется внутри приложения в технический адрес вида `username@duckgomz.app`. Пользователь вводит только имя и пароль; телефон и email в интерфейсе не запрашиваются.

## Сборка APK

Требуются JDK 17 и Android SDK 36.

```bash
cd android
./gradlew assembleDebug
```

APK будет создан здесь:

```text
android/app/build/outputs/apk/debug/app-debug.apk
```

## Ограничения прототипа

Регистрация Android выполняется через Firebase Auth. Переписка и вложения пока локальные, а ответ бота демонстрационный: для настоящей доставки сообщений и файлов на сервер Duckgomz потребуется подключить серверную часть и задать правила хранения.
