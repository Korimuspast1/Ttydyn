# ТОСКА — дворы

Маленькая 2D-прогулка по русскому двору. Поздняя осень, 19:47, дождь. Пятиэтажка, парковка с «Ладой», хоккейная коробка, качели, гаражи, кот и бабушка на лавочке.

![двор](docs/preview-dvor.jpg)
![площадка](docs/preview-ploshchadka.jpg)
![магазин](docs/preview-magazin.jpg)

Всё нарисовано кодом на canvas — спрайтов нет. Звук (дождь, ветер, шаги, скрип качелей, урчание кота, далёкий гудок) тоже генерируется процедурно через Web Audio.

## Производительность

Кадр специально сделан дешёвым — иначе на слабых машинах лагает:

- **Земля, дальний город, дома** запекаются в спрайты один раз при старте.
- **Деревья, фонари, лавки, машины, коробка, остановка, гаражи, площадка** —
  тоже спрайты (раньше это были тысячи векторных фигур в каждом кадре).
- **Свет** (фонари, окна, подъезды, небо) запекается в один мягкий слой и
  накладывается одним блтом; в кадре остаются только фары проезжающих машин.
- **Дождь, круги на лужах** используют предрасчитанные таблицы вместо
  тригонометрии в каждом кадре; **туман и виньетка** — кэшированные спрайты.
- **Зерно плёнки** живёт в CSS-слое и композитится на GPU, не трогая canvas.
- **Адаптивное качество**: игра следит за временем кадра и сама снижает
  разрешение (dpr 1.5 → 1 → 0.75) и отключает самые дорогие эффекты,
  если кадр дольше ~34 мс, и возвращает их обратно, когда становится легче.

Замеры (операций canvas за кадр): было ~19 900 (4 300 заливок, 1 370 обводок,
86 градиентов, 4 160 эллипсов) — стало ~1 800 (120 заливок, 290 обводок,
10 градиентов, 150 эллипсов).

## Проверки

```bash
npm install
npm run dev
```

Открыть `http://localhost:5173`.

Сборка: `npm run build` → `dist/`.

## Управление

| Клавиша | Действие |
|---|---|
| `WASD` / стрелки | идти |
| `Shift` | бежать |
| `E` | взаимодействовать / дальше / встать |
| `Q` | зонт |
| `F` | фонарик |
| `M` | звук вкл/выкл |
| `Esc` | закрыть мысль |

На телефоне — джойстик слева, кнопки `E` и `☂` справа.

## Что можно потрогать

Лавочки (сесть), качели (покачаться), карусель, песочница, контейнеры, трансформаторная будка с «ЦОЙ ЖИВ», хоккейная коробка, мяч, кот (пойдёт за тобой), голуби (взлетят), автобусная остановка, радио на подоконнике, домофон, «Продукты 24», гаражи, дорога, бабушка Зинаида Петровна и Серёга с «Ладой».

Мысли появляются сами: при входе в новые места, после долгой прогулки и при взаимодействии.

```

tools/smoke.mjs     прогон движка в Node с заглушкой canvas (ищет ошибки)
```

## Мелочи, которые стоит заметить

- Часы идут: одна игровая минута ≈ 11 секунд.
- Свет в окнах разный: тёплый, холодный, где-то мерцает телевизор.
- На дороге изредка проезжают машины, слышно, как они приближаются и уходят.
- Из люка идёт пар, у Серёги дымит сигарета, на холоде видно дыхание.
- В лужах отражается свет и персонаж.
- `node tools/smoke.mjs` — быстрый прогон на ошибки без браузера (заглушка canvas).
- `node tools/collide.mjs` — проверка коллизий: сквозь объекты не пройти,
  до каждого интерактивного объекта можно дойти, все тропинки проходимы.
- `node tools/bench.mjs` — считает операции canvas за кадр в разных точках двора
  (нужен `@napi-rs/canvas`).
- `npm i --no-save @napi-rs/canvas && node tools/shot.mjs` — реальные скриншоты игры в `/tmp/shots` без браузера.
