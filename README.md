# 🚗 SoftBody Drive 2D

2D-игра про езду на машине с **soft-body физикой в стиле BeamNG.drive**:
кузов собран из точек и балок, поэтому он по-настоящему мнётся, балки
пластично деформируются и рвутся, подвеска пружинит, а колёса могут отлететь.

## Как играть

Просто открой `index.html` в браузере — или подними локальный сервер:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Управление

| Клавиша | Действие |
|---|---|
| `W` / `↑` | газ |
| `S` / `↓` | тормоз / задний ход |
| `A` `D` / `←` `→` | наклон машины в воздухе |
| `Shift` | нитро |
| `Space` | ручник |
| `R` | ремонт / респаун |
| `P` | пауза |

На телефоне есть сенсорные кнопки.

## Что внутри

- Бесконечный случайный мир: ландшафт генерируется из сида (номер мира — в HUD), каждая загрузка — новая трасса
- Минималистичный интерфейс и полностью без звука

- Собственный физический движок на Verlet-интеграции (120 Гц, итерационные связи-балки)
- Пластичность металла: после удара кузов остаётся мятым, пока не нажмёшь `R`
- Разрушаемые деревянные ящики и бочки, холмы с трамплинами, разметка дистанции
- Частицы пыли/искр/дыма, тряска камеры при ударах
- Никаких зависимостей — только `index.html`, `style.css`, `game.js`

Цель — проехать как можно дальше и не разбить машину. Удачи! 🏁
